# Placeholder as label

- Signature: 0c796cbb
- Severity: Moderate
- WCAG: 4.1.2 Name, Role, Value (Level A)
- URL: https://demo-fe-orpin.vercel.app/
- Selector: input

- Source file: components/Footer.js

## Evinced remediation guidance

**Cause:** 
The input element is labeled only by a placeholder attribute. 
**Effect:** 
When users start typing, placeholder text disappears, making it easy to forget what information is needed. This creates barriers for those with cognitive disabilities and memory issues, who require consistent labels throughout the form completion process. 
**Suggested Solutions:**
Do the following: 
1. Add persistent text instead of the disappearing placeholder. 
2. Logically connect this text to the input by wrapping the text in a label element. Set a `for` attribute on the label with the corresponding input's ID as the `for` attribute value: 
<label for="fn">Full Name</label> 
<input id="fn" type="text">
